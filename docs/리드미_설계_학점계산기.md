# 리드미 설계: 학점 계산기

2026-11-19. 초안이다. 서버와 화면은 2026-11-19에 만들었다(`transcript` 패키지, 프런트 `/settings/grades`, 4.1). 실제 성적증명서와 실제 Claude로는 아직 읽어 보지 않았다. 시안은 캔버스 "리드미 최종 시안 (클릭 프로토타입)"의 설정 쪽 "학점 계산기 · 올리기", "학점 계산기 · 결과"이고, 시안에는 제안으로 그려져 있다(https://claude.ai/artifact/X9QDH9ajn7fCF19zyQxriu).

- 2절의 "정함"은 2026-11-19의 사용자 결정이다. "가정"은 이 문서가 채운 값이고, 다르게 만들어야 하면 만들기 전에 묻는다.
- 파일 읽기는 자료 올리기의 코드(`extraction`의 `UploadedFiles`, 경험카드 문서 4.4·4.7)를 다시 쓴다.
- 등급별 평점과 환산은 6절의 출처에서 확인했다.

## 1. 범위

성적증명서를 올리면 과목마다 학년, 학기, 이수구분, 과목명, 학점, 성적을 읽는다. 화면이 합계(총 취득학점, 평점평균, 전공 평점, 환산)를 내고, 지원서 칸에 붙여 넣게 복사해 준다. 자리는 설정의 기본 프로필 아래다.

이 문서에 없는 것: 읽은 결과 저장, 기본 프로필의 학점 칸에 넣기(GC8), 학교별 환산표, 4.0 만점(6절).

## 2. 정한 것

| # | 항목 | 정한 값 | 이유 |
|---|---|---|---|
| GC1 | 읽는 곳 | **정함**: 서버로 보내 읽는다 | 자료 올리기의 PDF·사진 읽기를 다시 쓴다. 브라우저에서만 읽으려면 PDF·OCR 패키지를 새로 넣어야 한다 |
| GC2 | 저장 | **정함**: 서버는 파일과 읽은 결과를 저장하지 않는다. 요청을 처리하는 동안 메모리에만 있다. 읽는 데 Claude API를 쓰므로 파일 내용은 Anthropic으로 간다. LLM 사용액(토큰 수와 금액)만 `llm_usage`에 남는다. 화면은 "저장하지 않습니다"와 함께 AI로 읽는다는 것을 알린다 | 시안의 "올린 파일과 결과는 저장하지 않습니다. 이 화면을 나가면 사라집니다" |
| GC3 | 파일 | **정함**: PDF는 10MB, 사진(JPG, PNG, GIF, WebP)은 5MB까지. 한 번에 한 파일. 스캔한 PDF는 20쪽까지 | 시안은 "PDF, JPG, PNG · 10MB까지"다. 사진은 Claude가 받는 크기가 5MB다(경험카드 문서 4.7) |
| GC4 | 만점 | **정함**: 4.5가 기본이고 화면에서 4.3으로 바꿀 수 있다. 바꾸면 등급별 평점(3절)과 합계가 그 만점으로 다시 계산된다. **가정**: 성적증명서에 만점이 적혀 있어 서버가 읽었으면(`scale`) 그 값으로 시작한다 | 국내 대학은 대부분 4.5이고 일부가 4.3이다(6절) |
| GC5 | 등급 | **정함**: 등급별 평점은 3절의 표다. 고른 만점의 표에 없는 등급(4.5에서 A- 등)과 읽지 못한 등급은 평점에서 빠지고 "확인 필요"로 보인다 | 학교마다 다를 수 있어 화면에서 성적 칸을 고칠 수 있게 한다 |
| GC6 | P/F | **정함**: P, S는 취득학점에만 넣고 평점에서 뺀다. NP, U는 둘 다에서 뺀다. F는 평점에 0으로 넣고 취득학점에서 뺀다. **가정**: P/F 과목의 F와 등급 과목의 F를 가리지 않는다 | 시안과 6절 |
| GC7 | 환산 | **정함**: 단순 비례다. 다른 만점 = 평점 ÷ 지금 만점 × 다른 만점, 100점 = 평점 ÷ 지금 만점 × 100. 화면에 "회사마다 환산표가 다르니 지원서 안내를 따르세요"를 붙인다 | 시안. 학교와 기관마다 환산표가 달라 하나로 정할 수 없다(6절) |
| GC8 | 기본 프로필의 학점 칸에 넣기 | **정함**: 이번에는 만들지 않는다 | 시안의 "정해야 할 것"에 남아 있다 |
| GC9 | 한도 | **가정**: 읽을 때마다 올린 사람의 LLM 사용액에 넣고, 한도에 닿았으면 읽지 않는다(429 `LLM_LIMIT_REACHED`) | 다른 LLM 기능과 같다(정리 문서 7절) |

## 3. 계산 규칙

화면이 계산한다(프런트의 순수 함수). 서버는 읽은 줄만 준다.

등급별 평점:

| 등급 | 4.5 만점 | 4.3 만점 |
|---|---|---|
| A+ | 4.5 | 4.3 |
| A0 | 4.0 | 4.0 |
| A- | 없음 | 3.7 |
| B+ | 3.5 | 3.3 |
| B0 | 3.0 | 3.0 |
| B- | 없음 | 2.7 |
| C+ | 2.5 | 2.3 |
| C0 | 2.0 | 2.0 |
| C- | 없음 | 1.7 |
| D+ | 1.5 | 1.3 |
| D0 | 1.0 | 1.0 |
| D- | 없음 | 0.7 |
| F | 0 | 0 |

- 평점평균 = Σ(등급의 평점 × 학점) ÷ Σ(학점). 표에 있는 등급의 과목만 센다.
- 총 취득학점 = F, NP, U가 아닌 과목의 학점 합. 시안의 예시 코드는 모든 과목을 더하지만 예시에 F가 없다.
- 전공 평점 = 이수구분이 "전공"으로 시작하는 과목의 평점평균.
- 자릿수: 평점은 소수 둘째 자리까지, 100점 환산은 첫째 자리까지 보이고 그 아래는 버린다(시안).
- 재수강: "재수강 전 성적 빼기"가 켜져 있으면(처음 값) `retake`가 `before`인 줄을 합계와 복사에서 뺀다.
- 묶기: 학기별, 학년별, 이수구분별. 묶음마다 학점 합, 평점, 과목 수를 보인다.
- 복사: 칸 하나, 줄 하나, 묶음 하나, 전체. "표로 복사"는 칸 사이를 탭으로 나누고 묶음 앞에 머리 줄(이수구분, 과목명, 학점, 성적)을 둔다. "글로 복사"는 한 줄에 `과목명 (이수구분) N학점 성적`이다.
- 확인 필요 칸(`unsure`)은 노란 입력 칸이다. 고친 값은 합계와 복사에 바로 들어간다. 성적은 대문자로 바꾸고 `A`처럼 기호가 없으면 `A0`로 본다.

## 4. API

| API | 하는 일 |
|---|---|
| `POST /api/transcripts/read` | 성적증명서 한 파일(multipart, 칸 이름 `file`)을 읽어 과목 줄을 돌려준다. 저장하지 않는다. 로그인한 사람만 부른다 |

응답:

```json
{
  "school": "예시대학교",
  "department": "컴퓨터공학과",
  "scale": 4.5,
  "courses": [
    { "year": 1, "term": "1", "category": "전공필수", "name": "프로그래밍기초", "credit": 3, "grade": "A+", "retake": null, "unsure": [] },
    { "year": 1, "term": "2", "category": "교양선택", "name": "미적분학2", "credit": 3, "grade": "C+", "retake": "before", "unsure": [] },
    { "year": 2, "term": "2", "category": "전공선택", "name": "데이터통신", "credit": 3, "grade": "B0", "retake": null, "unsure": ["credit"] }
  ]
}
```

- `school`, `department`: 성적증명서에 적힌 학교와 학과. 못 읽으면 `null`.
- `scale`: 성적증명서에 적힌 만점(`4.5`, `4.3`). 적혀 있지 않거나 다른 값이면 `null`.
- `courses`: 성적증명서에 나온 순서. `year`는 학년(1부터), `term`은 `"1"`, `"2"`, `"여름"`, `"겨울"`. **가정**: 학년 없이 연도로만 적힌 성적증명서는 처음 나온 연도를 1학년으로 센다.
- `category`: 이수구분. 줄임말은 풀어 쓴다(전필 → 전공필수, 전선 → 전공선택, 교필 → 교양필수, 교선 → 교양선택, 일선 → 일반선택). 그 밖은 적힌 그대로다.
- `credit`: 숫자. `grade`: 대문자와 기호로 맞춘 등급(`A+`, `A0`, `A-` … `F`, `P`, `NP`, `S`, `U`). `A`, `Ao`는 `A0`다.
- `retake`: `"before"`(재수강하기 전의 성적), `"after"`(재수강한 성적), 아니면 `null`. 성적증명서의 재수강 표시로 읽는다.
- `unsure`: 확실히 읽지 못한 칸의 이름(`"credit"`, `"grade"`). 없으면 빈 목록이다.

오류(이름은 초안이다):

| 코드 | 상태 | 때 |
|---|---|---|
| `TRANSCRIPT_TOO_LARGE` | 413 | PDF 10MB, 사진 5MB, 스캔한 PDF 20쪽을 넘는다. 읽은 글이 3만 자를 넘을 때도 같고, 그때는 메시지가 다르다(4.1) |
| `TRANSCRIPT_UNSUPPORTED_TYPE` | 415 | PDF와 사진이 아니다 |
| `TRANSCRIPT_UNREADABLE` | 422 | 손상되었거나 암호가 걸렸거나 글자를 읽지 못했다 |
| `TRANSCRIPT_NO_COURSES` | 422 | 읽었지만 과목 줄을 찾지 못했다(성적증명서가 아니다) |
| `LLM_LIMIT_REACHED` | 429 | 이번 달 한도에 닿았다 |
| `LLM_UNAVAILABLE` | 503 | Claude를 부를 수 없다 |

### 4.1 만들면서 정한 것

2026-11-19, 서버(`transcript`).

- 저장(GC2): 파일과 결과는 요청 동안의 메모리와 임시 파일(multipart, PDF 읽기)에만 있고 끝나면 지운다.
- 글의 주민번호·전화번호 꼴은 자료 올리기처럼 가리고(`PersonalNumbers`) Claude에 보낸다. 학번, 학수번호, 연도는 걸리지 않는다. 스캔본과 사진은 파일 그대로 옮겨 적기로 가므로 그 단계에서는 가리지 못한다.
- 읽는 길: 파일의 글은 자료 올리기의 코드로 읽는다(`extraction`의 `UploadedFiles.pdfOrImageText`). 글자 층이 있는 PDF는 PDFBox로, 스캔한 PDF와 사진은 Claude로 옮겨 적는다(`DOCUMENT_READ`). 그 글을 Claude에 한 번 더 보내 과목 줄을 받는다(`LlmFeature.TRANSCRIPT_READ`, effort low, 출력 상한 16,000, 프롬프트 `prompts/transcript-read.md`). 그래서 스캔본과 사진은 LLM을 두 번 부르고 사용액도 둘 다 남는다.
- 형식은 파일의 앞부분으로 먼저 본다. PDF와 JPG·PNG·GIF·WebP가 아니면(DOCX, HWP, TXT, TIFF, HEIC 등) 읽기 전에 415다. 크기도 형식을 안 뒤에 본다(PDF 10MB, 사진 5MB). 20MB를 넘는 파일은 multipart 상한에서 막혀 같은 413이다.
- 한도(GC9)는 파일을 읽기 전에 본다.
- 읽은 글이 3만 자를 넘으면 Claude에 보내지 않고 `TRANSCRIPT_TOO_LARGE`(413)다. 성적증명서는 몇천 자라서 사용액을 아낀다. 파일이 작아도 생기는 일이라 메시지는 크기 안내가 아니라 "글이 너무 깁니다. 성적증명서는 3만 자까지 읽습니다. 성적증명서만 담긴 파일인지 확인해 주세요"다(2026-11-19 사용자 결정. 그 전에는 422 `TRANSCRIPT_NO_COURSES`였다).
- Claude가 답을 만들지 못하면(거절, 출력 상한에 걸림, 형식이 틀림. `LLM_FAILED`) 502가 아니라 `TRANSCRIPT_UNREADABLE`(422)이다. 스캔본 옮겨 적기의 실패와 같게 둔다.
- 메시지: `TRANSCRIPT_TOO_LARGE`는 "파일이 너무 큽니다. PDF는 10MB, 사진은 5MB, 스캔한 PDF는 20쪽까지 읽습니다"(글이 길 때는 위의 글), `TRANSCRIPT_UNSUPPORTED_TYPE`는 "PDF나 사진(JPG, PNG, GIF, WebP) 파일만 읽습니다", `TRANSCRIPT_UNREADABLE`는 "파일을 읽지 못했습니다. 손상되었거나 암호가 걸렸거나 글자가 잘 보이지 않는 파일일 수 있습니다", `TRANSCRIPT_NO_COURSES`는 "과목을 찾지 못했습니다. 성적증명서 파일인지 확인해 주세요".
화면(2026-11-19, `features/settings`의 `grade-rules.ts`, `grades-page.tsx`):

- 예시 41과목은 `features/settings/grade-example.ts`에 두고, 가짜 서버(`mocks/transcript-db.ts`)에는 `api.ts`가 넘긴다(층 규칙상 `mocks`는 기능의 값을 불러오지 못한다).
- 노란 칸: `unsure`인 칸과, 고른 만점의 표에 없는 성적(4.5의 A- 등, GC5)이다. 노란 칸인지는 읽은 값으로 정해 고치는 동안 칸이 바뀌지 않는다. "확인 필요 N칸"도 읽은 값으로 센다.
- 학기 순서는 학년 안에서 1, 여름, 2, 겨울이다. 학기 수는 계절학기를 포함해 학년·학기가 다른 것을 센다. 이수구분별 묶기는 전공필수, 전공선택, 교양필수, 교양선택, 일반선택 다음에 나머지를 나온 순서대로 둔다. 비어 있는 이수구분·학기는 "이수구분 없음", "학기 없음"으로 묶는다.
- 평점을 매길 과목이 없으면 평점을 "-"로 보인다.
- 고친 학점이 숫자가 아니면 칸 아래에 알리고 읽은 값으로 계산한다. 쉼표 소수("3,0")는 받는다.
- 오류 글은 화면이 코드마다 정한다(서버 글을 쓰지 않는다). 본문 없는 413도 "너무 크다"로 본다.
- 읽지 못한 성적(`""`)이나 표에 없는 성적의 학점도 3절대로 총 취득학점에 들어간다. 고치기 전까지는 F일 수도 있는 줄을 더하는 셈이다(정할 것).

서버:

- 서버가 맞추는 것(`TranscriptReader.normalize`, LLM이 맞춰 주기를 믿지 않는다):
  - 이수구분 줄임말 다섯을 푼다. 그 밖은 앞뒤 공백만 지운다. 없으면 `""`.
  - 등급은 공백을 지우고 대문자로, 전각 `＋`·`－`와 `−`·`–`를 `+`·`-`로 바꾼다. `A`~`D` 한 글자와 `AO`(`Ao`)는 `A0`~`D0`다. 4절의 등급(`A+` … `F`, `P`, `NP`, `S`, `U`)이 아니면 적힌 대로 두고 `unsure`에 `"grade"`를 넣는다(읽지 못한 등급은 `""`).
  - 학기는 `여름`·`하계`가 들어 있으면 `"여름"`, `겨울`·`동계`면 `"겨울"`, `1`·`1학기`·`제1학기`는 `"1"`, 2도 같다. 그 밖은 적힌 그대로다.
  - 학점은 글자 속 첫 숫자다(`"3.0"` → `3`, `"1.50"` → `1.5`). 읽지 못하면 `0`이고 `unsure`에 `"credit"`을 넣는다. 10을 넘으면 값은 두고 `unsure`에 `"credit"`을 넣는다(칸이 밀려 점수 95가 학점으로 온 경우).
  - 학년: 적힌 학년(1~6)을 쓴다. 학년 칸의 1900 이상은 연도로 본다(연도 칸이 비었으면 그 값). 두 자리 연도(`19`)는 2000을 더한다. 1~6 밖의 학년은 없는 것으로 본다. 학년이 없으면 학년도·연도로 센다. 4절의 가정 "처음 나온 연도를 1학년"은 가장 이른 연도로 셈한다(성적증명서가 연도 순이면 같고, 순서가 섞여도 0학년이 나오지 않는다). 휴학한 해도 센다(2019년 1학년이면 2021년은 3학년). 학년도 연도도 없는 줄은 앞 줄의 학년(첫 줄이면 1)이다.
  - `retake`는 `"before"`·`"after"`(대소문자 무시)가 아니면 `null`. `unsure`는 `"credit"`, `"grade"`만, 이 순서로 둔다.
  - `scale`은 4.5나 4.3일 때만, 그 밖은 `null`. `school`·`department`가 비면 `null`.
  - 과목명이 빈 줄은 뺀다. 남은 줄이 없으면 `TRANSCRIPT_NO_COURSES`다.
- 응답의 `credit`은 소수점 아래 0을 뗀 숫자다(`3`, `1.5`).

## 5. 프런트와 맞출 것

1. 위 응답 꼴을 그대로 쓴다. 가짜 서버(`npm run dev`)는 시안의 예시 성적(41과목)을 돌려준다. 시안의 "예시 성적증명서로 보기"는 서버를 부르지 않고 같은 예시를 보인다.
2. 화면은 보내기 전에 형식과 크기(GC3)를 본다.
3. 시안의 "2 / 3쪽" 진행과 "보통 10초 안에 끝납니다"는 연출이다. 서버는 진행을 알려 주지 않고 읽는 데 수십 초가 걸릴 수 있으므로, 화면은 읽는 중이라는 것과 걸리는 시간만 알린다.
4. 시안의 합계는 "4.3 만점 환산"이 고정이다. 만점을 고를 수 있게 했으므로(GC4) 4.5를 고르면 4.3 환산을, 4.3을 고르면 4.5 환산을 보인다. 만점 고르기는 시안에 없는 칸이다.
5. 주소는 `/settings/grades`(가정)이고 설정의 왼쪽 메뉴에서 기본 프로필 아래다.
