# 리드미 설계: 학점 계산기

2026-11-19. 초안이다. 서버와 화면에 아직 없다. 시안은 캔버스 "리드미 최종 시안 (클릭 프로토타입)"의 설정 쪽 "학점 계산기 · 올리기", "학점 계산기 · 결과"이고, 시안에는 제안으로 그려져 있다(https://claude.ai/artifact/X9QDH9ajn7fCF19zyQxriu).

- 2절의 "정함"은 2026-11-19의 사용자 결정이다. "가정"은 이 문서가 채운 값이고, 다르게 만들어야 하면 만들기 전에 묻는다.
- 파일 읽기는 자료 올리기의 코드(`extraction`의 `UploadedFiles`, 경험카드 문서 4.4·4.7)를 다시 쓴다.
- 등급별 평점과 환산은 6절의 출처에서 확인했다.

## 1. 범위

성적증명서를 올리면 과목마다 학년, 학기, 이수구분, 과목명, 학점, 성적을 읽는다. 화면이 합계(총 취득학점, 평점평균, 전공 평점, 환산)를 내고, 지원서 칸에 붙여 넣게 복사해 준다. 자리는 설정의 기본 프로필 아래다.

이 문서에 없는 것: 읽은 결과 저장, 기본 프로필의 학점 칸에 넣기(GC8), 학교별 환산표, 4.0 만점(6절).

## 2. 정한 것

| # | 항목 | 정한 값 | 이유 |
|---|---|---|---|
| GC1 | 읽는 곳 | **정함**: 서버로 보내 읽는다 | 자료 올리기의 PDF·사진 읽기를 다시 쓴다. 브라우저에서만 읽으려면 PDF·OCR 패키지를 새로 넣어야 한다 |
| GC2 | 저장 | **정함**: 서버는 파일과 읽은 결과를 저장하지 않는다. 요청을 처리하는 동안 메모리에만 있다. 읽는 데 Claude API를 쓰므로 파일 내용은 Anthropic으로 간다. LLM 사용액(토큰 수와 금액)만 `llm_usage`에 남는다. 화면은 "저장하지 않습니다"와 함께 AI로 읽는다는 것을 알린다 | 시안의 "올린 파일과 결과는 저장하지 않습니다. 이 화면을 나가면 사라집니다" |
| GC3 | 파일 | **정함**: PDF는 10MB, 사진(JPG, PNG, GIF, WebP)은 5MB까지. 한 번에 한 파일. 스캔한 PDF는 20쪽까지 | 시안은 "PDF, JPG, PNG · 10MB까지"다. 사진은 Claude가 받는 크기가 5MB다(경험카드 문서 4.7) |
| GC4 | 만점 | **정함**: 4.5가 기본이고 화면에서 4.3으로 바꿀 수 있다. 바꾸면 등급별 평점(3절)과 합계가 그 만점으로 다시 계산된다. **가정**: 성적증명서에 만점이 적혀 있어 서버가 읽었으면(`scale`) 그 값으로 시작한다 | 국내 대학은 대부분 4.5이고 일부가 4.3이다(6절) |
| GC5 | 등급 | **정함**: 등급별 평점은 3절의 표다. 고른 만점의 표에 없는 등급(4.5에서 A- 등)과 읽지 못한 등급은 평점에서 빠지고 "확인 필요"로 보인다 | 학교마다 다를 수 있어 화면에서 성적 칸을 고칠 수 있게 한다 |
| GC6 | P/F | **정함**: P, S는 취득학점에만 넣고 평점에서 뺀다. NP, U는 둘 다에서 뺀다. F는 평점에 0으로 넣고 취득학점에서 뺀다. **가정**: P/F 과목의 F와 등급 과목의 F를 가리지 않는다 | 시안과 6절 |
| GC7 | 환산 | **정함**: 단순 비례다. 다른 만점 = 평점 ÷ 지금 만점 × 다른 만점, 100점 = 평점 ÷ 지금 만점 × 100. 화면에 "회사마다 환산표가 다르니 지원서 안내를 따르세요"를 붙인다 | 시안. 학교와 기관마다 환산표가 달라 하나로 정할 수 없다(6절) |
| GC8 | 기본 프로필의 학점 칸에 넣기 | **정함**: 이번에는 만들지 않는다 | 시안의 "정해야 할 것"에 남아 있다 |
| GC9 | 한도 | **가정**: 읽을 때마다 올린 사람의 LLM 사용액에 넣고, 한도에 닿았으면 읽지 않는다(429 `LLM_LIMIT_REACHED`) | 다른 LLM 기능과 같다(정리 문서 7절) |

## 3. 계산 규칙

화면이 계산한다(프런트의 순수 함수). 서버는 읽은 줄만 준다.

등급별 평점:

| 등급 | 4.5 만점 | 4.3 만점 |
|---|---|---|
| A+ | 4.5 | 4.3 |
| A0 | 4.0 | 4.0 |
| A- | 없음 | 3.7 |
| B+ | 3.5 | 3.3 |
| B0 | 3.0 | 3.0 |
| B- | 없음 | 2.7 |
| C+ | 2.5 | 2.3 |
| C0 | 2.0 | 2.0 |
| C- | 없음 | 1.7 |
| D+ | 1.5 | 1.3 |
| D0 | 1.0 | 1.0 |
| D- | 없음 | 0.7 |
| F | 0 | 0 |

- 평점평균 = Σ(등급의 평점 × 학점) ÷ Σ(학점). 표에 있는 등급의 과목만 센다.
- 총 취득학점 = F, NP, U가 아닌 과목의 학점 합. 시안의 예시 코드는 모든 과목을 더하지만 예시에 F가 없다.
- 전공 평점 = 이수구분이 "전공"으로 시작하는 과목의 평점평균.
- 자릿수: 평점은 소수 둘째 자리까지, 100점 환산은 첫째 자리까지 보이고 그 아래는 버린다(시안).
- 재수강: "재수강 전 성적 빼기"가 켜져 있으면(처음 값) `retake`가 `before`인 줄을 합계와 복사에서 뺀다.
- 묶기: 학기별, 학년별, 이수구분별. 묶음마다 학점 합, 평점, 과목 수를 보인다.
- 복사: 칸 하나, 줄 하나, 묶음 하나, 전체. "표로 복사"는 칸 사이를 탭으로 나누고 묶음 앞에 머리 줄(이수구분, 과목명, 학점, 성적)을 둔다. "글로 복사"는 한 줄에 `과목명 (이수구분) N학점 성적`이다.
- 확인 필요 칸(`unsure`)은 노란 입력 칸이다. 고친 값은 합계와 복사에 바로 들어간다. 성적은 대문자로 바꾸고 `A`처럼 기호가 없으면 `A0`로 본다.

## 4. API

| API | 하는 일 |
|---|---|
| `POST /api/transcripts/read` | 성적증명서 한 파일(multipart, 칸 이름 `file`)을 읽어 과목 줄을 돌려준다. 저장하지 않는다. 로그인한 사람만 부른다 |

응답:

```json
{
  "school": "예시대학교",
  "department": "컴퓨터공학과",
  "scale": 4.5,
  "courses": [
    { "year": 1, "term": "1", "category": "전공필수", "name": "프로그래밍기초", "credit": 3, "grade": "A+", "retake": null, "unsure": [] },
    { "year": 1, "term": "2", "category": "교양선택", "name": "미적분학2", "credit": 3, "grade": "C+", "retake": "before", "unsure": [] },
    { "year": 2, "term": "2", "category": "전공선택", "name": "데이터통신", "credit": 3, "grade": "B0", "retake": null, "unsure": ["credit"] }
  ]
}
```

- `school`, `department`: 성적증명서에 적힌 학교와 학과. 못 읽으면 `null`.
- `scale`: 성적증명서에 적힌 만점(`4.5`, `4.3`). 적혀 있지 않거나 다른 값이면 `null`.
- `courses`: 성적증명서에 나온 순서. `year`는 학년(1부터), `term`은 `"1"`, `"2"`, `"여름"`, `"겨울"`. **가정**: 학년 없이 연도로만 적힌 성적증명서는 처음 나온 연도를 1학년으로 센다.
- `category`: 이수구분. 줄임말은 풀어 쓴다(전필 → 전공필수, 전선 → 전공선택, 교필 → 교양필수, 교선 → 교양선택, 일선 → 일반선택). 그 밖은 적힌 그대로다.
- `credit`: 숫자. `grade`: 대문자와 기호로 맞춘 등급(`A+`, `A0`, `A-` … `F`, `P`, `NP`, `S`, `U`). `A`, `Ao`는 `A0`다.
- `retake`: `"before"`(재수강하기 전의 성적), `"after"`(재수강한 성적), 아니면 `null`. 성적증명서의 재수강 표시로 읽는다.
- `unsure`: 확실히 읽지 못한 칸의 이름(`"credit"`, `"grade"`). 없으면 빈 목록이다.

오류(이름은 초안이다):

| 코드 | 상태 | 때 |
|---|---|---|
| `TRANSCRIPT_TOO_LARGE` | 413 | PDF 10MB, 사진 5MB, 스캔한 PDF 20쪽을 넘는다 |
| `TRANSCRIPT_UNSUPPORTED_TYPE` | 415 | PDF와 사진이 아니다 |
| `TRANSCRIPT_UNREADABLE` | 422 | 손상되었거나 암호가 걸렸거나 글자를 읽지 못했다 |
| `TRANSCRIPT_NO_COURSES` | 422 | 읽었지만 과목 줄을 찾지 못했다(성적증명서가 아니다) |
| `LLM_LIMIT_REACHED` | 429 | 이번 달 한도에 닿았다 |
| `LLM_UNAVAILABLE` | 503 | Claude를 부를 수 없다 |

## 5. 프런트와 맞출 것

1. 위 응답 꼴을 그대로 쓴다. 가짜 서버(`npm run dev`)는 시안의 예시 성적(41과목)을 돌려준다. 시안의 "예시 성적증명서로 보기"는 서버를 부르지 않고 같은 예시를 보인다.
2. 화면은 보내기 전에 형식과 크기(GC3)를 본다.
3. 시안의 "2 / 3쪽" 진행과 "보통 10초 안에 끝납니다"는 연출이다. 서버는 진행을 알려 주지 않고 읽는 데 수십 초가 걸릴 수 있으므로, 화면은 읽는 중이라는 것과 걸리는 시간만 알린다.
4. 시안의 합계는 "4.3 만점 환산"이 고정이다. 만점을 고를 수 있게 했으므로(GC4) 4.5를 고르면 4.3 환산을, 4.3을 고르면 4.5 환산을 보인다. 만점 고르기는 시안에 없는 칸이다.
5. 주소는 `/settings/grades`(가정)이고 설정의 왼쪽 메뉴에서 기본 프로필 아래다.
