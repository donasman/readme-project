# 리드미 설계 초안: 로그인·경험카드 (나눔)

2026-11-13에 이 문서를 둘로 나눴다. 내용은 아래 문서에 있다. 이 문서는 옛 절과 가정 번호가 어디로 갔는지만 남긴다. 코드 주석에 이 문서의 절을 가리키는 곳이 있어서 지우지 않았다.

- `docs/리드미_설계_로그인.md`: 계정 테이블, 로그인 API, 구글 로그인
- `docs/리드미_설계_경험카드.md`: 카드·자료·추출 테이블, 카드 API, jobfit에서 옮길 것
- `docs/리드미_백엔드_구조.md`: 모든 API에 걸리는 규칙, 스키마, Supabase 조건
